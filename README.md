# recipes

A personal collection of high-protein, low-carb, non-animal-protein recipes.

## Goals

- **Low carb** — to help manage type 2 diabetes.
- **Non-animal protein** — to avoid kidney stones / high uric acid (animal protein, especially meat and seafood, is a major purine/uric acid driver).

Dairy and eggs are in scope (they're low-purine relative to meat), but the
main proteins are tofu, tempeh, edamame, seitan, and legumes.

## Rough targets per serving

- Protein: 20g or more
- Net carbs (total carbs minus fiber): 15g or less

These are guidelines, not hard rules — some recipes will trade off a bit on
one to hit the other.

## Layout

All recipes live in [`recipes/`](recipes/) as individual markdown files.
Use [`recipes/_template.md`](recipes/_template.md) as a starting point for
new ones.
