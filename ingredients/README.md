# Ingredients

Reference photos for ingredients that can be hard to find or identify in
stores — packaging shots, where to look in the store, or which brand/variety
to grab.

Name files after the ingredient, e.g. `beefless-bouillon.jpg`,
`high-protein-tofu.jpg`. Add a short note in a recipe's `## Notes` section
if a photo here is relevant to it.
