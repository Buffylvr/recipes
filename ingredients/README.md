# Ingredients

Reference material for ingredients that can be hard to find or identify in
stores, organized into three subfolders:

- [`pictures/`](pictures/) — reference photos (packaging shots, what to look for on the shelf).
- [`locations/`](locations/) — one master document (`locations/README.md`) listing where to buy each ingredient and which brand/variety to grab.
- [`nutritional-information/`](nutritional-information/) — nutrition facts for specific products, for when the exact numbers matter for a recipe's macros.

Name photo files after the ingredient, e.g. `tempeh.png` in `pictures/`.
Add a short note in a recipe's `## Notes` section if something here is
relevant to it.
